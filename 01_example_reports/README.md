# Example Reports

This directory contains example scan reports generated by **Project 01 – Website Crawler & Broken Link Checker**.

The reports were created using publicly accessible websites specifically intended for testing, QA practice, web automation, or crawler-related exercises. They were used only to test and demonstrate the functionality of the tool.

## Test Websites

### Site Example
https://www.site-example.com/

A website intended for testing web crawlers, scrapers, link checkers, and QA automation.

### TestingURL.dev
https://testingurl.dev/

A testing website containing examples such as broken links, redirects, redirect chains, and redirect loops.

### QA Practice
https://www.qapractice.com/

A website providing practice applications and scenarios for QA and test automation.

## Note

The websites listed above are third-party websites and are not affiliated with this project.

The reports are provided only as examples of the tool's functionality. No ownership of the tested websites or their content is claimed.
