# Bug Evidence

This directory contains video evidence for the four defects identified during manual testing of **The Dig Game**.

Each recording demonstrates the observed issue and helps illustrate the conditions under which it occurs. The videos can be viewed locally if downloaded or directly through the Loom links provided below.

## Purpose

The recordings provide visual evidence supporting the corresponding bug reports in the main QA documentation workbook. They help demonstrate the observed behavior and support defect analysis and reproducibility.
