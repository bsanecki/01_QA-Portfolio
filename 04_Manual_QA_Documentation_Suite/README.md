# 04 – Manual QA Documentation Suite

This project showcases my manual QA testing skills, including test case design, test execution, bug reporting, and test documentation.

I have completed numerous test cases and tests on crowdsourced testing platforms such as **uTest, Test IO**, and similar platforms. However, due to confidentiality rules and platform policies, I cannot publicly share the original test cases, reports, screenshots, or project-specific information.

This repository will contain independent testing examples and documentation that demonstrate my practical QA skills while respecting confidentiality requirements.
