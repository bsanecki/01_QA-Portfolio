# Postman API Testing

A collection of Postman exercises, API testing practice and projects created while learning REST API testing.

The repository documents my progress with testing REST APIs using Postman, from basic HTTP requests and response validation to more advanced API test scenarios.

## Contents

- **Collections** — Postman collections and API test cases
- **Environments** — environment configurations
- **Projects** — practical API testing projects
- **Test Results** — test execution results and evidence
- **Bug Reports** — documented API issues and defects
- **Notes** — notes related to Postman and REST API testing

## Goal

The goal of this section is to develop practical skills in REST API testing and become comfortable with using Postman as part of a QA testing workflow.
