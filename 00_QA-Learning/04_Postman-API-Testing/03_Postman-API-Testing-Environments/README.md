# Postman API Testing + Environments

Practical API testing project created to practice core Postman features used in QA testing.

## Scope

- Environments and variables
- `{{baseUrl}}` and dynamic variables
- Authentication and token handling
- Request chaining
- Pre-request scripts
- Post-response test scripts and assertions
- Positive and negative testing
- Data-driven testing
- Collection Runner

The project uses the ReqRes API and demonstrates how requests can be connected, parameterized and automatically validated.
