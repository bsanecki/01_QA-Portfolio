# Postman API CI/CD

Automated API testing with Postman, Newman and GitHub Actions.

## Tech Stack

- Postman
- JavaScript
- Newman
- GitHub Actions
- REST API

## Features

- Automated API tests
- CI/CD pipeline
- PASS/FAIL detection
- HTML and JSON test reports
- Timestamped test results

Tests are automatically executed through GitHub Actions after changes to the repository.
