# DummyJSON API Testing

API testing project created in **Postman** using **DummyJSON**, a public fake REST API designed for development, testing, prototyping, and learning.

## Scope

* Authorization
* Products
* Carts
* Users
* Positive and negative testing
* Input and boundary validation
* Response assertions
* Test scripts
* Collection Runner

## Deliverables

* Postman collection with API tests
* Automated assertions and test scripts
* Collection Runner results
* QA findings and bug report documentation

**Test API:** https://dummyjson.com/
**Documentation:** https://dummyjson.com/docs

> DummyJSON is a demo/testing API. Its write operations are simulated and are not intended to represent persistent production data.
