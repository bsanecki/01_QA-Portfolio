# Appium Calculator Tests

Automated testing of the Android Calculator app using Python, Pytest and Appium.

## Project Overview
This project contains automated UI tests that verify basic calculator functionality, including arithmetic operations and input handling.

## Technologies
- Python
- Pytest
- Appium
- Android UIAutomator2

## Running Tests
Start the Appium server, activate the virtual environment and run:

```bash
python -m pytest -v
```
