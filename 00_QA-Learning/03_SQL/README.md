# SQL

A collection of SQL exercises, queries and practical projects created while learning and developing my database skills.

The repository documents my progress with SQL and focuses on practical database operations and data analysis relevant to QA and Test Engineering.

## Topics

- SELECT and filtering
- JOINs
- GROUP BY and aggregate functions
- Subqueries
- INSERT, UPDATE and DELETE
- Data validation
- Database testing
- Practical SQL projects

## Goal

The goal of this section is to build a solid understanding of SQL and database operations that can be applied in software testing and QA automation.
