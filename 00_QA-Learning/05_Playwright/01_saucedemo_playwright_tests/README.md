# 01 – Playwright SauceDemo

Automated tests for **SauceDemo** using **Python, Pytest and Playwright**.

**SauceDemo** is a demo web application created specifically for learning and practicing software testing and test automation.

🌐 **Website:** https://www.saucedemo.com/

## Test Coverage

- Valid and invalid login
- Locked-out user login
- Product visibility
- Adding and removing products from the cart
- Cart contents
- Product sorting
- Checkout form validation
- Complete checkout process

## Technologies

- Python
- Pytest
- Playwright
