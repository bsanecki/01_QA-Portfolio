# 02 – Playwright Automation Exercise

Automated E2E tests for **Automation Exercise** using **Python, Pytest and Playwright**.

**Automation Exercise** is a demo web application created for practicing software testing and test automation.

🌐 **Website:** https://automationexercise.com/

## Test Coverage

- Homepage loading
- User registration
- Valid login
- Invalid login
- User logout
- Product search
- Product details
- Adding products to the cart
- Adding multiple products to the cart
- Complete checkout and order placement

## Technologies

- Python
- Pytest
- Playwright
