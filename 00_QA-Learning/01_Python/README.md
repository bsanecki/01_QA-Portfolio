# Python Projects

A collection of Python projects created while learning and improving my programming skills.

The projects cover different areas of Python, including object-oriented programming, working with files and data, automation, simulations, and practical CLI applications.

They were created at different stages of my learning process, so the complexity and code quality may vary between projects. Some projects are older and reflect my earlier programming experience, while others were created more recently to practice specific Python concepts.

## Projects

- **Test Data Generator** - generates test users and stores the data in JSON.
- **Transform Sentence** - a small programming task focused on string processing and character comparison.
- **Log Analyzer** - analyzes application logs and generates statistics and reports.
- **Animal Simulation** - an object-oriented simulation of animals moving and interacting in a virtual environment.
- **Library System** - a CLI application for managing books, users and loans.
