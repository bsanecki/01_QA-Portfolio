# Database & Data Validation

A Python and pytest project created to practice automated database testing and data validation using SQL and SQLite.

The tests verify database structure, record counts, relationships, required fields, unique values, email formats, valid ranges, statuses and other data quality rules.

The database also contains a few intentionally introduced data errors. They are used to verify that the automated tests can correctly detect invalid or inconsistent data.

## Technologies

- Python
- pytest
- SQLite
- SQL
