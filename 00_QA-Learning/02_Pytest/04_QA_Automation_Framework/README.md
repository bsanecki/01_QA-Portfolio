# QA Automation Framework

A Python test automation project created to practice Pytest and common QA automation techniques.

The project focuses on testing a simulated order pricing system with discounts, taxes, validation, calculation history and external service dependencies.

## What is tested

- Unit testing
- Service-layer testing
- Fixtures
- Parametrization
- Mocking
- Exception handling
- Input validation
- External service dependencies
- Test markers
