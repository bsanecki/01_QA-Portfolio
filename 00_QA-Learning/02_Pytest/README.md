# Pytest - Test Automation

A collection of Python test automation projects created while learning and practicing pytest.

## Projects

### 01. API Test Automation
Automated REST API tests using pytest and requests.

### 02. Data-Driven Testing
Data-driven tests using pytest parametrization, fixtures and external test data.

### 03. Database & Data Validation
Automated database and data validation tests using pytest and SQL.

### 04. QA Automation Framework
A complete pytest-based automation framework combining fixtures, parametrization, mocking, reporting and CI.

## Technologies

- Python
- pytest
- requests
- SQL
- Git
- GitHub Actions

## Goal

The goal of this repository is to demonstrate practical experience with Python test automation and pytest, from basic tests to larger QA automation frameworks.
