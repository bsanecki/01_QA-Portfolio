# API Test Automation

A small Python project created to practice API testing with pytest and requests.

The project tests REST API endpoints using different HTTP methods and verifies response status codes, headers, JSON data and response times.

## Tests

- GET requests
- POST requests
- PUT requests
- PATCH requests
- DELETE requests
- Positive and negative test cases
- JSON response validation
- HTTP headers validation
- Response time validation
- Parametrized tests
- Pytest fixtures

## Technologies

- Python
- pytest
- requests

## Run

```bash
python3 main.py
